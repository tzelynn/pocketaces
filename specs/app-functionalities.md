## pocket-aces

one-stop app to make credit card application decisions, and track credit card usage, bills and fees


## app usage

- can be used from the website or installed as an app on android and apple phones
- have an update button to pull the latest published version of the site


## key functionalities

- credit card summary page
    - summarizes all the credit card information scraped, for user to choose which credit card is best for them
    - filter by miles or cashback, presence of min spend, expenditure type (e.g. travel, transport, etc)
    - sort by reward value, max reward spending cap, min spend
    - allow adding to 'my credit cards', to be highlighted at the top for easy reference
    - allow for a notes column to type personal notes for each card
- my credit card bill and fee dates
    - tracks when each credit card bill is issued, due, and when the fees will be billed (to request for waiver)
    - allow for check-off after bill payment or waiver, refreshed each month/year accordingly
    - send reminders 1 week before a bill that is due has not been paid
    - send reminder when a credit card fee is supposed to be incurred so user can request for waiver
    - manual tracking whether min spend and max spend for each card has been hit (to guide user on which card to use for next purchase)
- must be able to store user data reliably in the browser and/or app


## design principles

- simple and clean layouts that are aesthetically pleasing and organized
    - can tolerate some witty and whimsical elements but do not overdo it or make it too tacky
- use of simple and aesthetic icons (not emojis) for certain fields to avoid the site looking too wordy
- compatible with phone and laptop screen views
